                          ⚙️  HELPER СКРИПТЫ
═══════════════════════════════════════════════════════════════════════════════

Windows (docker-helper.bat):
  docker-helper.bat start    - Запустить приложение
  docker-helper.bat stop     - Остановить приложение
  docker-helper.bat logs     - Показать логи приложения
  docker-helper.bat health   - Проверить health status
  docker-helper.bat ps       - Показать работающие контейнеры
  docker-helper.bat clean    - Очистить контейнеры и volumes

Linux/Mac (docker-helper.sh):
  bash docker-helper.sh start     - Запустить приложение
  bash docker-helper.sh stop      - Остановить приложение
  bash docker-helper.sh logs      - Показать логи приложения
  bash docker-helper.sh logs app  - Логи приложения
  bash docker-helper.sh health    - Проверить health status
  bash docker-helper.sh ps        - Показать работающие контейнеры
  bash docker-helper.sh clean     - Очистить контейнеры и volumes

Для обратной совместимости:
- Приложение работает локально (без Docker) с application.properties
- В Docker используется application-docker.properties через Spring profile

Для остановки:
  docker-compose down           # Останавливает контейнеры
  docker-compose down -v        # Удаляет контейнеры И volumes (БД)

Для просмотра логов:
  docker-compose logs -f app    # Логи приложения
  docker-compose logs -f postgres
  docker-compose logs -f mongodb
